# 檐下听雨场景验收清单

## 自动检查

- [ ] `scene_manifest.json` 与 `timeline.json` 可解析。
- [ ] 所有 `track_id` 唯一，所有 `master_file` 均存在于 `audio/master/`。
- [ ] 所有文件为 48 kHz、双声道 PCM WAV。
- [ ] 全部真峰值 `≤ -3 dBTP`，综合响度符合图层区间。
- [ ] `loop=true` 的轨均填写 `requires_engine_crossfade` 与合法 `crossfade_ms`。

## 人工试听

- [ ] A01、A02、A03 分别连续循环至少 2 分钟，接缝无断点、鼓包、掉音或明显周期感。
- [ ] A04 在 3:08 与 7:38 各单次触发；自然起止、不突兀、不抢主雨声，不得被引擎循环。
- [ ] 手机外放：A02 可辨识但不刺耳；A01 稳定承托；A03 只提供细节；A04 不抢注意。
- [ ] 耳机：拖动距离有层次，左右位置自然，无快速绕头或贴耳压迫。
- [ ] 0:00–0:30、3:08、3:40、5:30、7:38、8:50、9:20、10:20 等关键节点无硬切。
- [ ] 离线情况下四条本地资源可完整播放；单条资源缺失时其余轨道仍可运行。
- [ ] 整场无音乐、人声、雷声、鸟叫和突发高频刺激。

全部试听通过且 A04 来源页、许可证或购买凭证归档后，把对应资产状态由 `qc_pending` 改为 `master`，并将 `scene_manifest.release_ready` 改为 `true`。
