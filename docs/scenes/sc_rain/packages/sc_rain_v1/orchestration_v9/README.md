# sc_rain orchestration_v9｜檐下听雨正式编排

- 提交规范：`preset-orchestration-submission-v1`
- 当前线上基线：`sc_rain_v1` timeline v8
- 正式编排版本：v9
- 场景总时长：620 秒（10:20）
- 场景类型：无人声、无文本、无音乐的雨景环境预设

## 场景听感目标

场景从一层清脆、近处的竹叶雨开始，让听者先建立明确的单声源参照。竹叶雨依次经历由近到远、由左到右、向外退出的连续空间变化；随后檐下雨、远雨和竹叶雨共同建立完整雨景。长段保持檐下雨为主、远雨承托、竹叶雨点缀，阵风只在两个时刻从远处短暂掠过，结尾逐层退远并淡出。

同一个声音的位置变化和多个声音的层次建立均属于正式场景叙事，并沿统一的 620 秒主时钟执行。

## 正式层级关系

- A02「檐下雨」：39 秒进入时 radius `0.50`，之后逐渐靠近，始终是最响的主环境。
- A01「远雨」：radius `0.85`，位于左前方，作为明显更轻的连续承托。
- A03「竹叶雨」：完成开场退出后，以 radius `0.93` 从右后方重新进入，作为最轻、最清脆的细节层；长段最近只到 `0.90`，仍轻于远雨。
- A04「阵风」：只在 188 秒、458 秒播放两次，始终偏远，不作为持续底层。

## 圆盘退出与重新进入

position 表的合法 radius 上限为 `1.00`。00:34–00:39 的退出写为：竹叶雨移动到右后方边缘，39 秒 `C_A03_SOLO` 结束，圆盘图标进入退出/删除态。

39.0–39.2 秒之间没有活动的 A03 clip，因此 `G_A03` 可在 39.1 秒于同一方位从边缘半径重置到细节层半径；39.2 秒 `C_A03_LAYER` 开始淡入。两条 clip 同属一个 `G_A03`，任何时刻都只能生成一个「竹叶雨」逻辑声源图标。

## 自动化口径

`automation.csv` 仅保留表头，表示没有 clip 边界之外的额外自动化。所有淡入淡出只由 `clips.csv` 定义，不得二次叠加。稳态主次全部由 position 表中的 radius 表达，不使用 `default_volume`。
