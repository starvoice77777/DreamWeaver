# 真机远程联调：已实现能力与测试清单

> 分支：`integration/frontend-backend`  
> 适用：Windows 跑 API + Mac/Xcode 真机安装  
> 更新：2026-08-04

---

## 一、当前已实现能力（验收范围）

### 1. 客户端运行模式

| 能力 | 说明 |
|------|------|
| 本地演示 | Bundle + 本地 Service，可离线演示 |
| 远程 API | 冷启动生效；设置里切换后需完全退出重开 |
| 远程基址 | `dw.apiBaseURL`；真机默认局域网 IP，可在设置中改并保存 |
| 局域网 HTTP | `NSAllowsLocalNetworking` 已开 |

### 2. 内容与播放

| 能力 | 说明 |
|------|------|
| 官方场景目录 | 远程 `GET /v1/scenes` + 详情；本地 Mock 兜底 |
| 时间线编排 | `GET /v1/scenes/{id}/timeline`；客户端调度分层进场 |
| 本地多轨播放 | `LocalPlaybackService` + AVAudioEngine；圆盘改混音实时同步 |
| 场景切换 | 卡片进「此刻」、上下滑切场景、封面/时间线预取 |
| 官方混音预设 | 服务端 2 条：洗头轻声、细雨慢听；「此刻」底部 **我的 \| 预设** 可选 |
| 定时 | 自动 / 10 / 30 / 60 / 一直；演示加速（演示控制开启时） |

### 3. 账号与云端状态

| 能力 | 说明 |
|------|------|
| 开发登录 | `dev:demo-user`（联调主路径） |
| Sign in with Apple | 真机可用（需 Bundle `zhimeng.DreamWeaver.df` + Capability） |
| 会话保持 | Keychain token；冷启动可保持登录 |
| 收藏官方场景 | 登录后 patch scene-state；home 恢复 |
| 用户设置同步 | 自动播放等 ↔ `PUT/GET /v1/users/me/settings` |
| 云端保存混音 | 设置页「云端保存当前混音」（显式保存） |
| Home | 收藏 / 最近 / 私人场景摘要 |

### 4. 声音库与种子（远程需登录）

| 能力 | 说明 |
|------|------|
| 资产列表 | 登录后拉 `/v1/library/assets` |
| 上传 / 删除 | 需登录；未登录有明确提示 |
| 声音种子流程 | 质检 → 授权 → 任务 → 保存（Stub 供应商） |

### 5. 工程 / 联调配置

| 项 | 当前值 |
|----|--------|
| Team | `DF548S4JJY` |
| Bundle ID | `zhimeng.DreamWeaver.df` |
| `DW_APPLE_CLIENT_ID` | 与 Bundle 一致（见 `server/.env.example`） |
| 默认真机基址示例 | `http://192.168.120.62:8000`（换网需改） |

### 6. 明确不在本轮范围 / 已知占位

- 人声短句 `voice_phrase_mom` 可能仍为静音占位  
- 远程官方预设目前仅洗头、雨檐各 1 条；其它场景只有「我的」  
- 离线写队列完整回放尚未作为联调必测项  
- 勿恢复已删除的 `SceneDetailSheet` / `ScenePreviewView`
