# wind_realistic v2 处理与 QC 报告

## 定位与问题

- 原文件：`dw_official_env_wind_realistic_loop_sc_rain_far_v01_t01.wav`
- 该声音是偶尔出现的远风变化层，不应持续播放或抢占主雨声。
- 原始响度约 `-27.51 LUFS`，真峰值余量充足，动态和首尾较稳定，无需压缩或强降噪。

## 处理目的

1. 仅提升 1.5 dB，使其达到约 `-26 LUFS`，保留原始风声动态。
2. 不做额外立体声扩展、压缩或高频重塑，避免产生人工绕头感。
3. 另生成 32.71 秒演示长版，内部以 1000ms 等功率交叉淡化连接；单次 20 秒事件可直接取用该版本而不在事件内部循环。

两条均为 48 kHz、双声道、PCM 16-bit WAV；未覆盖原始文件。

## 时间线建议

- 第一次：`3:00–3:20`，`volume=0.18`，8 秒淡入、4 秒维持、8 秒淡出。
- 第二次：`7:30–7:50`，`volume=0.16`，从另一侧更远位置进入，同样 8 秒淡入和淡出。
- 使用 t01 时设 `requires_engine_crossfade=true`、`crossfade_ms=1000`；使用 t03 承担 20 秒事件时可关闭事件内循环。
- 两次事件应使用两个轨道实例，避免依赖播放器暂停后再次播放是否从头开始。

## 必须人工试听

1. 检查是否存在突然增强的阵风、低频轰鸣或持续高频风噪。
2. 与近檐雨叠加时确认风声只带来远景变化，不吸引持续注意。
3. t01 连续循环至少 2 分钟，检查 1000ms 工程交叉淡化。
4. t03 完整试听，确认两个内部连接点自然。

当前短素材可用于复赛演示；正式上架仍建议采集更长且变化更自然的母带，状态保持 `qc_pending`。
