# rain_soft v2 处理与 QC 报告

## 原始文件

`dw_official_amb_rain_soft_loop_sc_rain_far_v01_t01.wav`

- PCM 16-bit WAV，44.1 kHz，单声道，11.595986 秒。
- FFmpeg 实测：`-30.55 LUFS`、`-9.24 dBTP`、LRA `1.10 LU`。
- 未发现削波、明显直流偏移或首尾硬断点。
- 图层由 `amb` 改为 `env`：该素材承担持续播放的室内远雨底层。

## 处理原则

1. 使用 SoX Resampler 高精度重采样至 48 kHz。
2. 采用双声道 PCM WAV 输出。
3. 两遍 loudnorm 归一到约 `-25 LUFS`，真峰值上限 `-3 dBTP`。
4. 不做强降噪、压缩或频谱重塑，保留原始雨声动态。
5. 保留自然双声道版本，并另做轻度立体声备选。

## 单声道下混检查

- 自然版下混：`-28.01 LUFS`。
- 轻度立体声版下混：`-28.07 LUFS`。
- 两者仅相差约 `0.06 LU`，自动检测未发现明显相位抵消。

## 工程建议

- 默认使用 `v02_t01`；轻度立体声 `v02_t02` 仅在耳机与手机外放人工试听通过后采用。
- `v02_t01` 已配置为：`loop=true`、`requires_engine_crossfade=true`、`crossfade_ms=1000`。母带仍为 11.596 秒，场景播放窗口由时间线控制为 0:00–10:20。
- 0:00–0:30 从 0 淡入到 `volume=0.22`；9:20 开始以 60000ms 淡出，10:20 `pause + disable`。
- `v02_t03` 适合复赛演示或长试听，但源纹理仍来自同一段 11.6 秒录音，不能替代正式采集的长母带。
- 推荐默认 `volume=0.20–0.24`；距离效果只改变空间位置与衰减，不写入该增益。

## 必须人工试听

1. 戴耳机比较 `t01` 与 `t02`，确认 `t02` 没有空洞、漂移或梳状感。
2. 手机外放确认远雨仍可听见，但不会盖过近处檐雨。
3. 将 `t01` 连续循环至少 2 分钟，确认 1000ms 工程交叉淡化没有音量鼓包或下陷。
4. 完整听一遍 `t03`，确认约每 10.6 秒的内部连接点不明显，且重复纹理可以接受。
