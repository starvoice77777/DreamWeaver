# wind_gust v3 处理与 QC 报告

## 1. 来源与用途

- 原始文件：`foley-风-咆哮的阵风-大-音质量好-48000 1_爱给网_aigei_com.wav`
- 场景用途：`sc_rain` 中偶发的远处阵风变化，不承担持续环境底层。
- 资源键：`wind_gust`
- 图层 / 播放方式：`trigger + oneshot`
- 授权状态：`pending_verification`。文件名指向爱给网，原文件元数据包含 `acidplanet.com`；需补充下载页面、许可证或购买凭证并核对原始作者。

## 3. 处理版本

### 推荐母带 t01

`dw_official_trg_wind_gust_oneshot_sc_rain_far_v03_t01.wav`

- 高通 70 Hz：减轻低频轰鸣，降低手机外放浑浊感。
- 低通 9.5 kHz：柔化尖锐风噪，避免抢占注意力。
- 响度衰减：将综合响度统一到约 -26 LUFS。
- 输出：48 kHz、立体声、24-bit PCM WAV；清除继承的网页元数据。

实测：3.709 s，-26.02 LUFS，样本峰值约 -14.77 dBFS；远低于 -3 dBTP 上限，具备充足叠轨余量。

### 自然保留版 t02

`dw_official_trg_wind_gust_oneshot_sc_rain_far_v03_t02.wav`

- 仅做 -13 dB 响度衰减，不做频段修饰。
- 输出：48 kHz、立体声、24-bit PCM WAV；清除继承的网页元数据。

实测：3.709 s，-25.97 LUFS，样本峰值约 -13.67 dBFS。用于 A/B 试听，不进入正式时间线。

## 4. 时间线调整

- 原 A04 的 20 秒循环结构废止。
- A04 只建立一个轨道和一个 `track_id`，通过 `playback_events[]` 定义两次播放窗口。
- 第一次：3:08 单次触发，3.709 s，左后远处小范围移动，`volume=0.22`。
- 第二次：7:38 复用同一轨道并从素材开头单次触发，3.709 s，右后远处小范围移动，`volume=0.18`。
- 该轨使用 `loop=false`、`requires_engine_crossfade=false`、`crossfade_ms=0`；两次 cue 均执行 `play_oneshot`。
- 距离变化只由空间位置与客户端衰减曲线控制，不继续通过母带音量制造远近。

## 5. 人工验收项

- 手机外放：阵风可辨识但不能突然压过 A02 近檐雨。
- 耳机：移动始终停留在远侧，不得穿耳、绕头或贴近中心。
- 连续播放整场：两次出现均自然，不因 3.7 秒时长产生突兀感。
