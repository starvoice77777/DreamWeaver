# sc_rain orchestration_v9 变更记录

对比当前线上基线：`sc_rain_v1` timeline v8。

## 正式编排调整

- 场景开头改为单一竹叶雨声源：A03 `rain_bamboo_leaf` 从 0 秒淡入，先形成稀疏、清脆的近处开场。
- 18–39 秒使用同一个 A03 声源完成近到远、左到右和向外退出；不更换素材，不混入其他声源。
- 39 秒后才建立完整雨景：A01 与 A02 从 39 秒淡入，A03 从 39.2 秒以轻细节层重新进入。
- 42 秒之后继续沿统一主时钟执行完整长场景编排。

## 播放窗变更

- A01 `rain_soft`：由 v8 的 `0–620` 改为 `39–620`。
- A02 `rain_parasol`：由 v8 的 `30–560` 改为 `39–560`。
- A03 `rain_bamboo_leaf`：由 v8 的单段 `220–530` 改为两段；`0–39` 负责开场与空间过渡，`39.2–530` 负责正式雨景细节层。两段同属 `G_A03`。
- A04 `wind_gust`：仍在 `188` 秒与 `458` 秒各触发一次，事件数、时间点和资源未改。
- 场景总时长仍为 620 秒。

## 位置轨迹变更

- A03 18–24 秒：radius `0.38 → 0.78`，六秒连续变远；24–26 秒保持。
- A03 26–32 秒：angle `-55° → +55°`，六秒连续从左前移动到右前；32–34 秒保持。
- A03 34–38.8 秒：angle `+55° → +105°`、radius `0.78 → 1.00`；38.8–39 秒保持边缘后退出。
- A03 39.2 秒重新进入后 radius 为 `0.93`，长段最近为 `0.90`，始终轻于 A01。
- A02 39 秒以 radius `0.50` 进入并沿长场景逐渐靠近；A01 以 radius `0.85` 稳定承托。
- A01、A02、A03 结尾均逐层变远并淡出，不硬停。

## 未变更项

- 四个 WAV、母带文件名、`resource_key`、母带哈希、采样率、响度处理及许可证状态未变。
- 场景仍无 phrases、voice、music、雷声或鸟叫。
- 不使用稳态 volume；主次只通过 radius 表达。
- 不提交最终 JSON，由工程侧根据本目录 CSV 编译。

验收口令：**表能唯一描述预设；母带哈希与上一版相同。**
