# 真机离线验证清单（Mac + iPhone）

当前开发环境为 Windows，无法在此完成 Xcode 编译与真机验证。请持有 Mac 的队友按下列步骤执行，并将结果回填。

## 构建

1. 用 Xcode 打开 `DreamWeaver.xcodeproj`
2. 确认 `DreamWeaver/Resources/Audio/` 下音频出现在工程同步目录中
3. 真机或模拟器选择 iOS 17+
4. Build & Run，记录是否成功：`[ ] 成功  [ ] 失败（粘贴日志）`

## 标准演示（重置后）

1. 设置 → 演示控制 →「重置为标准演示状态」
2. 冷启动应进入「洗头陪伴」
3. 能听到水流 / 吹风机 / 空调底噪（人声短句当前可能为静音占位，待替换）
4. 打开场景详情，拖动声源：音量与左右声道明显变化
5. 选择「演示加速」：约 45 秒内分层渐隐并停止
6. 「我的」陪伴记录有更新
7. 「全部」进入「檐下听雨」可播雨+风
8. 声音库 → 创建声音种子：质检固定通过 → 授权 → 进度 → 保存并可加入场景
9. 关闭网络后重复上述流程仍可用
10. 重启 App 后上次场景与个人混音仍在；再次重置可回到统一起点
