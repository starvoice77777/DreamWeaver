# sc_rain orchestration_v9 试听验收记录

## 00:00–00:39 单声源开场

- 0 秒开始即有竹叶雨淡入，不得出现开场空白。
- 0–39 秒只允许听见 A03 竹叶雨；若出现宽阔远雨或连续檐下雨，说明 A01/A02 提前进入。
- 对比 18 秒与 24 秒：同一雨点应从较近、较清楚变为更远、更轻，素材音色本身不改变。
- 26–32 秒：耳机应明确听见同一竹叶雨由左前平滑移动到右前；手机外放至少可辨认声像重心变化。
- 34–39 秒：竹叶雨逐渐移远并退出，39 秒不得出现爆点或突兀硬切。
- 每段轨迹只单向移动一次，停留段不得回摆。

## 00:39–00:42 三层建立

- A01、A02 在 39 秒开始淡入，A03 细节层在 39.2 秒开始淡入；三层应在约两秒内自然建立，不能同时突然冲出。
- 41.2 秒后，檐下雨最清楚，远雨提供宽阔承托，竹叶雨只保留右后方清脆细节。
- 41.2–42 秒保持空间布局，不再做明显移动。

## 00:42–10:20 长场景

- 檐下雨始终是主层；远雨始终比主层轻；竹叶雨始终比远雨更轻。
- 188 秒和 458 秒的阵风只短暂掠过，不应压住主雨，也不得增加第三次事件。
- 530 秒后竹叶雨应完全退出；560 秒后只剩远雨。
- 560–620 秒远雨连续淡出并移向边缘，结尾不得硬停。
